01 ／ 問題與目標

產能是靠人數堆出來的
四個漏，正在吃掉毛利

01繪圖人力線性成長

案量增加 20%，人力就得增加 20%。成長的天花板是你的招募能力。

02兩套 3D、兩套真相

Blender 與 SketchUp 各做一份，版本對不上，改圖要改兩次。

03數量靠人工點

材料與工種太多，漏項要等決算才知道，毛利被吃掉還找不到原因。

043D 與施工圖各做一次

同一件事做兩遍；設計一改，兩邊都要重來。

施工圖工時／案300 → 220hr
現場變更2–4 → ≤1次
數量漏項率5–10% → ≤3%
可同時承接3–4 → 5–6案

只有第一項是你能控制的；後三項才是老闆在意的。工時降了但變更與漏項沒動，那只是「畫得快」。

02 ／ 做法

一套模型，三件事
產出、工具、時程

建一次模型 樓層、元件、材料、工種、尺寸
  • 施工圖平面／天花／立面／剖面／大樣
  • 3D 視覺同一模型直接渲染，不重做
  • 材料數量Qto 匯出，工種彙總
  • 變更紀錄改模型，圖與數量同步

價值不在「會做 3D」，而在「同一份資料被重複使用四次」。這就是小團隊能取代大團隊的技術本質。

角色工具負責什麼不要做什麼
核心模型Bonsai（Blender 外掛）樓層、分類、屬性、材料、工種拿來做圖框排版
出圖加速（1 席）BricsCAD BIM 或 Archicad圖框、標註、明細表、列印另建一套可獨立修改的模型
交換與檢核IFC ＋ Solibri／Bonsai IDS對外交付、衝突檢核、規則檢查把 IFC 當每天編輯的檔
數量與估價IfcOpenShell ＋ ExcelQto 匯出、工種彙總、損耗跳過人工覆核

鐵則正式施工模型只有一個。其他工具只能是前期設計、視覺、或補充；兩套並行＝兩倍重工。

  1. M0–1S0 基礎標準、選案、裝機門檻：試點範圍簽核
  2. M2–4S1 試點一案走完建模→出圖→IFC門檻：出圖可用率 ≥ 80%
  3. M5–8S2 資產化元件庫、樣板、腳本門檻：第二案工時 −30%
  4. M9–12S3 全面新案皆用 BIM 出圖門檻：4 個 KPI 達標
  5. M13–18S4 交付IFC 協作、竣工模型門檻：2 個外部單位收 IFC

沒過門檻就不進下一階段。這不是流程圖，是停損機制。

04 ／ 請裁決

今天可以決定的四件事

坑一：兩套圖並行

只要允許「先用 CAD 頂一下」，BIM 就會永遠停在頂一下。對策：驗收通過後才設 CAD 截止日，之前保留比對、不維護第二套。

坑二：業主只寫「要 BIM」

沒寫格式、精度、驗收，解釋權就不在你手上。對策：附一頁交付說明——IFC4、LOD 300、不含機電、不給原生檔、驗收三項可測。

我們不是要買一套軟體，
是要把「畫圖」變成「生產」。
